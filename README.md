# Pult for Homebrew

[Pult](https://getpult.app/) shares the serial consoles of your boards between you and your AI
agents, and keeps you in charge.

```sh
brew install --cask pultapp/tap/pult
```

This installs Pult.app and the `pult` command. Pult updates itself; `brew upgrade --greedy`
also works. `brew uninstall --zap pult` removes its settings and console recordings too.
